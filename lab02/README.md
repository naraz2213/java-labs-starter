# Вариант: Инженерия ИИ — класс `DataSample`

## Инварианты

Для любого корректно созданного объекта `DataSample` всегда верно:

1. `id` не равен `null` и не пустой (после `trim()`).
2. `label` не равен `null` и не пустой (после `trim()`).
3. `status` не равен `null`.
4. `features` не равен `null` и не пустой (длина > 0).
5. Все элементы `features` — конечные числа (не `NaN`, не бесконечность).
6. Поле `features` защищено:
   - в конструкторе массив копируется;
   - accessor возвращает копию массива.
7. Статус меняется только через метод `changeStatus(...)`.
8. Setter'ы для полей не создаются.

## Статусы (`SampleStatus`)

- `NEW` — создано, ещё не готово;
- `READY` — готово к использованию;
- `ARCHIVED` — заархивировано.

## Модель

- ничего не читает из консоли;
- ничего не печатает;
- предоставляет осмысленный публичный API.
